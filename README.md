# Project Chronicles Login Server

Autonomous C++20 authentication service. Owns account authentication, player sessions,
launcher grants, realm discovery and single-use world admissions. It serves launcher
news/content and optional signed patches. It does not run world simulation.

See [local installation and build instructions](SETUP.md).

Related repositories: [game-server](https://github.com/Project-Chronicles-Emulator/game-server),
[launcher](https://github.com/Project-Chronicles-Emulator/launcher),
[admin](https://github.com/Project-Chronicles-Emulator/admin).

See [service split validation](VALIDATION.md) for completed checks and limits.
